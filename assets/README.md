# assets/

Real screenshots of this exact build. There is no `terminal.png` on purpose:
the terminal (Ghostty + LazyVim + fish) is already visible in `editor.png`,
so the gallery runs with three captures.

| File | Shows |
| --- | --- |
| `desktop.png` | Clean desktop: wallpaper, Omacale bar on the left edge, idle |
| `editor.png` | Neovim on a Java project — `<leader>j` menu, jdtls inlay hints |
| `shell.png` | Omacale dashboard drawer + notification sidebar / quick settings |

## Conventions

- Native 1920×1080 PNG, no crops or browser chrome.
- Hide personal data before saving: file paths, notification contents, tabs.
- `SUPER+.` saves a fullscreen capture to `/data/midia/fotos/screenshots`;
  move and rename it here.
- Keep each file under ~2 MB.

## Embedding

`desktop.png` is the hero under **Desktop preview** in `README.md`;
`editor.png` and `shell.png` form the two-up **Gallery** table. Replacing a
file with the same name updates the README without any edit.
